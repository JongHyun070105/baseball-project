# Asset licenses

DIAMOND ROAD is local-only software. Local delivery does not remove the obligation to verify that every bundled asset may be copied and redistributed.

The current project uses only procedural geometry, CSS graphics, and runtime Web Audio signals authored in this repository. No third-party image, model, texture, font, music, or sound-effect file is bundled.

| Path | Kind | Source | License | Redistribution |
|---|---|---|---|---|
| `public/assets/.gitkeep` | Empty directory marker | Project authors | Original repository material | Allowed within this repository |

## Adding an asset

Before committing an asset, add one row per file or clearly bounded asset pack with:

- the repository-relative path;
- the original creator and direct source URL;
- the exact license name and version;
- required attribution text or notice location;
- whether modification and redistribution are allowed.

Do not add assets with unknown provenance, download-page-only links, noncommercial restrictions, or terms that prohibit repository redistribution. Keep a copy of required license text beside the asset when its license requires one.
